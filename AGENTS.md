# Project guidance

The root `package.json` owns the extension manifest for Git-URL installs; `service.mjs` selects the prebuilt backend. Preserve root installation and both platform-folder installations. `scripts/dependency-licenses.mjs` collects notices for actual nested package instances and embedded copies, not just top-level dependency names.

Use **Ideas Studio** for product names, UI titles, and generated-file attribution, and `ideas-studio-v2` as the extension ID on both platforms. This is an intentional new installation identity, not a compatibility alias. SurfSense and Google NotebookLM/Gemini belong in inspiration acknowledgements; preserve the recorded source attributions and required third-party license text. Keep fixture metadata free of personal/company identities and machine-specific paths. Use repository-relative or user-home-based paths in documentation; do not remove public provider/model identifiers as part of privacy cleanup.

Read `SPEC.md`, `README.md`, and `nextsteps.md` first; `nextsteps.md` holds the current plan and working setup. This is an independently distributed, optional extension, not part of OpenChamber's setup. Preserve `windows-11-x64/` and `linux-fedora-amd64/`; edit shared source in `shared/` and rebuild with `npm run build`. Ten of eleven formats are implemented; only Podcast appears as a disabled grid tile with no implementation. Infographic is drawn by AntV Infographic in a worker thread (`shared/service/builders/infographic*.mjs`) from a checked layout allowlist in `shared/common/infographic.mjs`; add a layout only after rendering it and checking every field shows. Iosevka (`shared/common/font.mjs`, `shared/fonts/`) is the default font for every supported surface; regenerate `Iosevka-metrics.json` with `node scripts/font-metrics.mjs` if the font files change. Preserve full Unicode coverage and the font-free infographic bridge preview. Sources are read by the service, never the panel (`shared/service/sources.mjs`, types in `shared/common/sources.mjs`); old `.doc`/`.xls`/`.ppt` files are read by Studio's own Compound File Binary reader in `shared/service/legacy*.mjs`; the current chat comes from `shared/service/chat.mjs` and is compressed by OpenCode only above 25,000 whitespace-separated words. The compressed summary also has a 150,000-character ceiling within the unchanged 200,000-character combined source budget. Document formats (Word, Slides, Spreadsheet, PDF) are validated in `shared/common/documents.mjs` and built by Node-only JavaScript builders in `shared/service/builders/`: no self-packaged Python, and the panel never imports the builders. Every bundled package and font needs license text; the build fails otherwise (vendored notices live in `shared/licenses/`). Password-protected, remote, and relay hosts are out of scope. Distinguish controlled tests from live model verification and untested platform builds. Studio is for everyone: a capable ten-year-old, an expert in another field, or someone new to technology. Use plain, respectful wording (no jargon, never talking down; no "ask a grown-up"). Pick sources, tap a tile, review Options, choose Create, open, and save, with defaults preselected. Quantity, length and detail labels show numeric targets that agree with their prompt hints and format limits; keep choice/default IDs stable for saved history. Slide totals include the added title slide, and Spreadsheet uses source tables with optional focus rather than an invented row target. Second pass is on by default: keep the validated draft and criticism private, then deliver only the complete revised result, under one normal job/spinner. Its saved toggle applies to future creations and is captured per job. Quiet recovery in `shared/service/jobs.mjs` shares two extra calls across all stages: at most five content-model calls with Second pass, three without; chat summarization is separate. Every actual call is recorded with its stage and outcome. Cancellation or a failed review/revision must never publish the draft as success. Technical detail is only under **About this**; generated files name sources plainly and never mention models or paths. Do not weaken authentication, truncate sources, or copy generated-code execution from upstream. Keep scratch work under `temp/` and generated history under `.studio/`, both out of commits.
